# Hero Bet Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 2-4 takımın kendi cihazlarından, oda koduyla katılıp gerçek zamanlı oynadığı açık artırma oyununu Vercel'de yayına hazır hale getirmek.

**Architecture:** Tek Next.js projesi. Tüm oyun kuralları `lib/game/` altında saf, bağımlılıksız bir motorda yaşar ve `applyAction(state, action, ctx)` imzasıyla çalışır. Route handler'lar ince: durumu yükle, motora sor, kaydet, Supabase Realtime Broadcast ile odadaki herkese tam anlık görüntü yayınla. İstemciler veritabanına asla yazmaz.

**Tech Stack:** Next.js (App Router) + TypeScript + Tailwind v4, Supabase (Postgres + Realtime), Vitest, Vercel.

**Spec:** `docs/superpowers/specs/2026-08-11-hero-bet-design.md`

## Spec'ten tek sapma (inceleme sırasında reddedilebilir)

Spec 6 normalize tablo öngörüyordu (`rooms`, `teams`, `items`, `lots`, `bids`, `votes`). Bu plan bunun yerine şunu kullanıyor:

- `rooms` satırı: `id`, `code` (unique), `status`, `state jsonb`, `updated_at`
- `bids`: append-only denetim kütüğü (oyun mantığı buradan okumaz)

**Gerekçe:** Motor tek bir `GameState` nesnesiyle çalışıyor ve mimari zaten "tam anlık görüntü yayınla" üzerine kurulu. 6 tabloyu her okumada nesneye çevirip her yazmada geri sökmek yüzlerce satır eşleme kodu demek, ve karşılığında hiçbir sorgu ihtiyacını karşılamıyor (odalar arası sorgu yok). `code` ve `status` indekslenebilir sütun olarak kalıyor, denetim kütüğü korunuyor.

**Geri dönüş maliyeti:** Sapma yalnızca Task 8'i etkiliyor. Normalize şema istenirse Task 8 yeniden yazılır, motor ve arayüz hiç değişmez.

## Global Constraints

- **Asgari teklif:** mevcut teklif + 1. Açılış teklifi asgari 1.
- **Varsayılanlar:** bütçe 10, ürün limiti 5, tur süresi 30 saniye.
- **Takım sayısı:** en az 2, en fazla 4. Koltuklar `0..n-1`, boşluksuz.
- **Oda kodu:** 4 karakter, alfabe `ABCDEFGHJKLMNPQRSTUVWXYZ23456789` (`0 O 1 I` yok).
- **Lot asla satılmadan kapanmaz.** Teklif yoksa en son pas geçen takıma bedelsiz (0) gider.
- **En son pas geçen hesabı:** limiti dolu takımlar lot açılışında elenir, hiç sıraya girmez ve devralamaz. Bütçesi yetmediği için otomatik pas geçenler hesaba katılır.
- **Sunucu otoritesi:** istemci veritabanına yazmaz. `turn_seq` her sıra değişiminde artar ve bayat istekleri reddeder.
- **Zaman aşımı ve ilerleme istekleri idempotenttir:** uygulanabilir değilse hata değil, boş sonuç döner.
- **Sonuç koreografisi:** `RESULT_MS = 2000`. Lot kapandıktan sonra sonraki lot ancak bu süre geçtikten sonra açılır.
- **Tek vurgu rengi:** `#FF4438`. Yalnızca baskı anlatır (sayaç, mevcut teklif, elenme). Onay/başarı/"sıra sende" için kullanılmaz; onlar `#EDEDED`.
- **Tek yarıçap sistemi:** 4px. Takım şeritleri keskin (0). Biletin perfore delikleri daire.
- **Animasyon:** yalnızca `transform` ve `opacity`. 150-250ms, `cubic-bezier(0.16, 1, 0.3, 1)`. `prefers-reduced-motion` altında geçişler düşer, süreler korunur.
- **Rakamlar:** her yerde `tabular-nums`.
- **Fontlar:** `next/font/google` ile self-host. Saira Condensed (display), Space Grotesk (gövde), JetBrains Mono (utility). Üretimde harici `<link>` yok.
- **Emoji ikon olarak kullanılmaz.** İkon gerekirse `@phosphor-icons/react`.
- **Dil:** tüm kullanıcıya görünen metin Türkçe. Kod, tip ve dosya adları İngilizce.
- **Em dash (`—`) kullanıcıya görünen metinde kullanılmaz.** Normal tire (`-`) kullanılır.
- **Masaüstü öncelikli**, `< 768px` tek sütuna iner. Tam yükseklik gerektiğinde `min-h-[100dvh]`.

```ts
import { describe, it, expect } from 'vitest';
import { createGame, applyAction } from '@/lib/game';
import type { GameState, Ctx } from '@/lib/game/types';

function ctx(nowMs = 1_000_000, start = 0): Ctx {
  let n = start;
  return { now: new Date(nowMs), newId: () => `id-${++n}` };
}

export function game(overrides: Partial<Parameters<typeof createGame>[0]> = {}): GameState {
  return createGame({
    roomId: 'room-1',
    code: 'AB23',
    hostTeamName: 'A',
    hostTeamId: 't-a',
    budget: 10,
    itemLimit: 5,
    turnSeconds: 30,
    ...overrides,
  });
}

describe('createGame', () => {
  it('lobide baslar ve host tek takimdir', () => {
    const s = game();
    expect(s.status).toBe('lobby');
    expect(s.teams).toHaveLength(1);
    expect(s.teams[0]).toMatchObject({ id: 't-a', name: 'A', seat: 0, budgetLeft: 10, itemsWon: 0 });
    expect(s.hostTeamId).toBe('t-a');
    expect(s.currentLotId).toBeNull();
  });
});

describe('START_GAME', () => {
  it('en az 2 takim yoksa reddeder', () => {
    const r = applyAction(game(), { type: 'START_GAME', byTeamId: 't-a' }, ctx());
    expect(r.ok).toBe(false);
    if (!r.ok) expect(r.error.code).toBe('NOT_ENOUGH_TEAMS');
  });

  it('host olmayan baslatamaz', () => {
    let s = game();
    s = { ...s, teams: [...s.teams, { id: 't-b', name: 'B', seat: 1, budgetLeft: 10, itemsWon: 0, connected: true }] };
    s = { ...s, items: [{ id: 'i-1', name: 'Ev', imageUrl: null }] };
    const r = applyAction(s, { type: 'START_GAME', byTeamId: 't-b' }, ctx());
    expect(r.ok).toBe(false);
    if (!r.ok) expect(r.error.code).toBe('NOT_HOST');
  });

  it('urun yoksa reddeder', () => {
    let s = game();
    s = { ...s, teams: [...s.teams, { id: 't-b', name: 'B', seat: 1, budgetLeft: 10, itemsWon: 0, connected: true }] };
    const r = applyAction(s, { type: 'START_GAME', byTeamId: 't-a' }, ctx());
    expect(r.ok).toBe(false);
    if (!r.ok) expect(r.error.code).toBe('NO_ITEMS');
  });

  it('ilk lotu acar, sirayi acan koltuktan baslatir ve son teslim anini kurar', () => {
    let s = game();
    s = {
      ...s,
      teams: [
        ...s.teams,
        { id: 't-b', name: 'B', seat: 1, budgetLeft: 10, itemsWon: 0, connected: true },
        { id: 't-c', name: 'C', seat: 2, budgetLeft: 10, itemsWon: 0, connected: true },

        { id: 'i-1', name: 'Ev', imageUrl: null },

      ],
    };

    expect(r.ok).toBe(true);
    if (!r.ok) return;

    expect(r.state.status).toBe('auction');
    expect(r.state.lots).toHaveLength(1);

    const lot = r.state.lots[0];
    expect(lot.lotNo).toBe(1);
    expect(lot.status).toBe('open');
    expect(lot.itemId).toBe('i-1');
    expect(lot.currentBid).toBeNull();
    expect(lot.activeTeamIds).toEqual(['t-a', 't-b', 't-c']);
    expect(lot.turnTeamId).toBe('t-a');

    expect(lot.activeTeamIds).toEqual(['t-b']);
```

`lib/game/types.ts`:

```ts
export type TeamId = string;
export type LotId = string;
export type ItemId = string;

export type RoomStatus = 'lobby' | 'auction' | 'voting' | 'finished';
export type BidKind = 'bid' | 'pass' | 'auto_pass';

export interface Team {
  id: TeamId;
  name: string;
  /** 0..n-1, bosluksuz. Sira bu dizilime gore doner. */
  seat: number;
  budgetLeft: number;
  itemsWon: number;
  connected: boolean;
}

export interface Item {
  id: ItemId;
  name: string;
  /** Bos olabilir. Bos oldugunda arayuz lot numarasini tipografik yedek olarak gosterir. */
  imageUrl: string | null;
}

export interface BidRecord {
  teamId: TeamId;
  kind: BidKind;
  /** Yalnizca kind === 'bid' oldugunda dolu. */
  amount: number | null;
  at: string;
}

export interface Lot {
  id: LotId;
  itemId: ItemId;
  /** 1'den baslar. */
  lotNo: number;
  status: 'open' | 'sold';
  currentBid: number | null;
  currentBidderTeamId: TeamId | null;
  turnTeamId: TeamId | null;
  /** Her sira degisiminde artar. Bayat istekleri reddetmek icin kullanilir. */
  turnSeq: number;
  turnDeadline: string | null;
  /** Bu lotta ilk siraya giren takim. Lot acildiginda belirlenir. */
  openerTeamId: TeamId | null;
  /** Bu lotta hala yarisan takimlar. Pas gecen cikarilir. */
  activeTeamIds: TeamId[];
  log: BidRecord[];
  winnerTeamId: TeamId | null;
  finalPrice: number | null;
}

export interface Vote {
  voterTeamId: TeamId;
  /** Voter disindaki tum takimlar, en iyiden en kotuye. */
  rankedTeamIds: TeamId[];
}

export interface GameState {
  roomId: string;
  code: string;
  status: RoomStatus;
  budget: number;
  itemLimit: number;
  turnSeconds: number;
  hostTeamId: TeamId;
  teams: Team[];
  items: Item[];
  /** Acilmis tum lotlar, acilis sirasinda. */
  lots: Lot[];
  /** Acik lot, ya da sonuc gosterilirken kapanmis son lot. */
  currentLotId: LotId | null;
  nextItemIndex: number;
  /** Sonraki lotu acacak koltuk. Her lotta bir ilerler. */
  openerSeat: number;
  /** Dolu oldugunda sonuc koreografisi oynuyor, yeni lot henuz acilmadi. */
  resultUntil: string | null;
  votes: Vote[];
}

export interface CreateGameInput {
  roomId: string;
  code: string;
  hostTeamId: TeamId;
  hostTeamName: string;
  budget?: number;
  itemLimit?: number;
  turnSeconds?: number;
}

export type Action =
  | { type: 'JOIN'; teamId: TeamId; name: string }
  | { type: 'SET_ITEMS'; byTeamId: TeamId; items: Item[] }
  | { type: 'START_GAME'; byTeamId: TeamId }
  | { type: 'BID'; teamId: TeamId; amount: number; turnSeq: number }
  | { type: 'PASS'; teamId: TeamId; turnSeq: number }
  | { type: 'TIMEOUT'; lotId: LotId; turnSeq: number }
  | { type: 'ADVANCE' }
  | { type: 'VOTE'; teamId: TeamId; rankedTeamIds: TeamId[] };
// Not: SET_PRESENCE aksiyonu Task 20'de eklenir.

export type GameEvent =
  | { type: 'TEAM_JOINED'; teamId: TeamId }
  | { type: 'LOT_OPENED'; lotId: LotId; lotNo: number; itemId: ItemId }
  | { type: 'TURN_CHANGED'; lotId: LotId; teamId: TeamId; deadline: string }
  | { type: 'BID_PLACED'; lotId: LotId; teamId: TeamId; amount: number }
  | { type: 'TEAM_PASSED'; lotId: LotId; teamId: TeamId; auto: boolean }
  | { type: 'LOT_SOLD'; lotId: LotId; winnerTeamId: TeamId; price: number; free: boolean }
  | { type: 'GAME_ENDED' }
  | { type: 'VOTING_STARTED' }
```

```ts
import type { GameState, Lot, Team, TeamId } from './types';

export function minBid(lot: Lot): number {
  return (lot.currentBid ?? 0) + 1;
}

/** Takimin urun limitinde yeri var mi. */
export function hasRoom(team: Team, state: GameState): boolean {
  return team.itemsWon < state.itemLimit;
}

/** Takim asgari teklifi verebilir mi. */
export function canAfford(team: Team, lot: Lot): boolean {
  return team.budgetLeft >= minBid(lot);
}

export function findTeam(state: GameState, id: TeamId): Team | undefined {
  return state.teams.find((t) => t.id === id);
}

export function teamAtSeat(state: GameState, seat: number): Team | undefined {
  return state.teams.find((t) => t.seat === seat);
}

/** currentLotId'nin gosterdigi lot, acik olsun ya da olmasin. */
export function currentLot(state: GameState): Lot | null {
  if (!state.currentLotId) return null;
  return state.lots.find((l) => l.id === state.currentLotId) ?? null;
}

export function openLot(state: GameState): Lot | null {
  const lot = currentLot(state);
  return lot && lot.status === 'open' ? lot : null;
}

/** Lot listesindeki bir lotu degistirip yeni state dondurur. */
export function withLot(state: GameState, lot: Lot): GameState {
  return { ...state, lots: state.lots.map((l) => (l.id === lot.id ? lot : l)) };
}

export function withTeam(state: GameState, team: Team): GameState {
  return { ...state, teams: state.teams.map((t) => (t.id === team.id ? team : t)) };
}

export function err(code: import('./types').RuleErrorCode, message: string) {
  return { ok: false as const, error: { code, message } };
}
```

```ts
import {
  DEFAULT_BUDGET,
  DEFAULT_ITEM_LIMIT,
  DEFAULT_TURN_SECONDS,
  MAX_TEAMS,
  MIN_TEAMS,
  RESULT_MS,

// Not: minBid ve openLot Task 3'te BID/PASS dallariyla birlikte eklenir.
// Simdi eklenirse kullanilmayan import lint hatasi verir.
import { canAfford, err, findTeam, hasRoom, teamAtSeat, withLot, withTeam } from './helpers';

  ApplyResult,
  CreateGameInput,
  Ctx,
  GameEvent,

export function createGame(input: CreateGameInput): GameState {
  const budget = input.budget ?? DEFAULT_BUDGET;
  return {
    roomId: input.roomId,
    code: input.code,
    status: 'lobby',
    budget,
    itemLimit: input.itemLimit ?? DEFAULT_ITEM_LIMIT,
    turnSeconds: input.turnSeconds ?? DEFAULT_TURN_SECONDS,
    hostTeamId: input.hostTeamId,
    teams: [
      {
        id: input.hostTeamId,
        name: input.hostTeamName,
        seat: 0,
        budgetLeft: budget,
        itemsWon: 0,
        connected: true,
      },
    ],
    items: [],
    lots: [],
    currentLotId: null,
    nextItemIndex: 0,
    openerSeat: 0,
    resultUntil: null,
    votes: [],
  };
}

/** Sonraki lotu acar; urun ya da yer kalmadiysa oyunu bitirir. */
function openNextLot(state: GameState, ctx: Ctx): { state: GameState; events: GameEvent[] } {
  const noItemsLeft = state.nextItemIndex >= state.items.length;
  const noRoomLeft = !state.teams.some((t) => hasRoom(t, state));
  if (noItemsLeft || noRoomLeft) return endGame(state);

  const item = state.items[state.nextItemIndex];
  const startSeat = state.openerSeat;

  const lot: Lot = {
    id: ctx.newId(),
    itemId: item.id,
    lotNo: state.lots.length + 1,
    status: 'open',
    currentBid: null,
    currentBidderTeamId: null,
    turnTeamId: null,
    turnSeq: 0,
    turnDeadline: null,
    openerTeamId: null,
    activeTeamIds: state.teams
      .filter((t) => hasRoom(t, state))
      .sort((a, b) => a.seat - b.seat)
      .map((t) => t.id),
    log: [],
    winnerTeamId: null,
    finalPrice: null,
  };

  const next: GameState = {
    ...state,
    lots: [...state.lots, lot],
    currentLotId: lot.id,
    nextItemIndex: state.nextItemIndex + 1,
    openerSeat: (state.openerSeat + 1) % state.teams.length,
    resultUntil: null,
  };

  const opened: GameEvent = {
    type: 'LOT_OPENED',
    lotId: lot.id,
    lotNo: lot.lotNo,
    itemId: lot.itemId,
  };

  const resolved = resolveTurn(next, lot.id, startSeat, ctx);
  return { state: resolved.state, events: [opened, ...resolved.events] };
}

/**
 * Siradaki uygun takimi bulur ve turu ona verir.
 * Parasi yetmeyen takimlari otomatik pas gecirerek atlar.
 * Uygun takim kalmadiysa lotu kapatir.
 */
function resolveTurn(
  state: GameState,
  lotId: string,
  cursorSeat: number,
  ctx: Ctx,
): { state: GameState; events: GameEvent[] } {
  const events: GameEvent[] = [];
  let s = state;
  let cursor = cursorSeat;
  const n = s.teams.length;

  // Her dongude en az bir takim aktiften cikar, bu yuzden n tur ust sinir.
  for (let guard = 0; guard <= n; guard++) {
    const lot = s.lots.find((l) => l.id === lotId)!;

    let candidate = null as null | { id: string; seat: number };
    for (let offset = 0; offset < n; offset++) {
      const seat = (cursor + offset) % n;
      const t = teamAtSeat(s, seat)!;
      if (!lot.activeTeamIds.includes(t.id)) continue;
      if (t.id === lot.currentBidderTeamId) continue;
      candidate = { id: t.id, seat: t.seat };
      break;
    }

    if (!candidate) {
      const closed = closeLot(s, lotId, ctx);
      return { state: closed.state, events: [...events, ...closed.events] };
    }

    const team = findTeam(s, candidate.id)!;

    if (!canAfford(team, lot)) {
      const passed: Lot = {
        ...lot,
        activeTeamIds: lot.activeTeamIds.filter((id) => id !== team.id),
        log: [
          ...lot.log,
          { teamId: team.id, kind: 'auto_pass', amount: null, at: ctx.now.toISOString() },
        ],
      };
      s = withLot(s, passed);
      events.push({ type: 'TEAM_PASSED', lotId, teamId: team.id, auto: true });
      cursor = candidate.seat + 1;
      continue;
    }

    const deadline = new Date(ctx.now.getTime() + s.turnSeconds * 1000).toISOString();
    const turned: Lot = {
      ...lot,
      turnTeamId: team.id,
      turnSeq: lot.turnSeq + 1,
      turnDeadline: deadline,
      openerTeamId: lot.openerTeamId ?? team.id,
    };
    s = withLot(s, turned);
    events.push({ type: 'TURN_CHANGED', lotId, teamId: team.id, deadline });
    return { state: s, events };
  }

  const closed = closeLot(s, lotId, ctx);
  return { state: closed.state, events: [...events, ...closed.events] };
}

/**
 * Lotu kapatir. Teklif varsa teklif sahibine satar,
 * yoksa en son pas gecen takima bedelsiz devreder.
 */
function closeLot(
  state: GameState,
  lotId: string,
  ctx: Ctx,
): { state: GameState; events: GameEvent[] } {
  const lot = state.lots.find((l) => l.id === lotId)!;

  let winnerId: string;
  let price: number;
  let free: boolean;

  if (lot.currentBid !== null && lot.currentBidderTeamId !== null) {
    winnerId = lot.currentBidderTeamId;
    price = lot.currentBid;
    free = false;
  } else {
    // Teklif yok: en son pas gecen takim devralir.
    const lastPass = [...lot.log].reverse().find((r) => r.kind !== 'bid');
    const startSeat = lastPass ? findTeam(state, lastPass.teamId)!.seat : state.openerSeat;
    const n = state.teams.length;
    let recipient = null as null | string;
    for (let i = 0; i < n; i++) {
      const t = teamAtSeat(state, (startSeat + i) % n)!;
      if (hasRoom(t, state)) {
        recipient = t.id;
        break;
      }
    }
    // openNextLot en az bir takimin yeri oldugunu garanti eder.
    winnerId = recipient!;
    price = 0;
    free = true;
  }

  const winner = findTeam(state, winnerId)!;
  let s = withTeam(state, {
    ...winner,
    itemsWon: winner.itemsWon + 1,
    budgetLeft: winner.budgetLeft - price,
  });

  s = withLot(s, {
    ...lot,
    status: 'sold',
    turnTeamId: null,
    turnDeadline: null,
    winnerTeamId: winnerId,
    finalPrice: price,
  });

  s = { ...s, resultUntil: new Date(ctx.now.getTime() + RESULT_MS).toISOString() };

  return {
    state: s,
    events: [{ type: 'LOT_SOLD', lotId, winnerTeamId: winnerId, price, free }],
  };
}

function endGame(state: GameState): { state: GameState; events: GameEvent[] } {
  const status = state.teams.length >= 3 ? 'voting' : 'finished';
  const events: GameEvent[] = [{ type: 'GAME_ENDED' }];
  if (status === 'voting') events.push({ type: 'VOTING_STARTED' });
  return {
    state: { ...state, status, currentLotId: null, resultUntil: null },
    events,
  };
}

export function applyAction(state: GameState, action: Action, ctx: Ctx): ApplyResult {
  switch (action.type) {
    case 'JOIN': {
      if (state.status !== 'lobby') return err('WRONG_STATUS', 'Oyun baslamis.');
      if (state.teams.length >= MAX_TEAMS) return err('ROOM_FULL', 'Oda dolu.');
      const seat = state.teams.length;
      return {
        ok: true,
        state: {
          ...state,
          teams: [
            ...state.teams,
            {
              id: action.teamId,
              name: action.name,
              seat,
              budgetLeft: state.budget,
              itemsWon: 0,
              connected: true,
            },
          ],
        },
        events: [{ type: 'TEAM_JOINED', teamId: action.teamId }],
      };
    }

    case 'SET_ITEMS': {
      if (state.status !== 'lobby') return err('WRONG_STATUS', 'Oyun baslamis.');
      if (action.byTeamId !== state.hostTeamId) return err('NOT_HOST', 'Yalnizca oda sahibi.');
      return { ok: true, state: { ...state, items: action.items }, events: [] };
    }

    case 'START_GAME': {
      if (state.status !== 'lobby') return err('WRONG_STATUS', 'Oyun baslamis.');
      if (action.byTeamId !== state.hostTeamId) return err('NOT_HOST', 'Yalnizca oda sahibi.');
      if (state.teams.length < MIN_TEAMS) return err('NOT_ENOUGH_TEAMS', 'En az 2 takim gerekli.');
      if (state.items.length === 0) return err('NO_ITEMS', 'Urun listesi bos.');
      const started = openNextLot({ ...state, status: 'auction' }, ctx);
      return { ok: true, state: started.state, events: started.events };
    }

    default:
      return err('WRONG_STATUS', 'Bu aksiyon henuz desteklenmiyor.');
  }
}
```

```ts
import type { GameState, TeamId } from './types';

export interface Standing {
  teamId: TeamId;
  points: number;
  firstPlaceVotes: number;
  budgetLeft: number;
  itemsWon: number;
  /** 1'den baslar. Puan, birincilik ve butce esitse takimlar ayni rank'i paylasir. */
  rank: number;
}

/**
 * Siralama oylamasini puana cevirir.
 * k rakip siralanmissa 1. siraya k, 2. siraya k-1 ... puan gider.
 * Beraberlik: birincilik oyu, sonra kalan butce.
 */
export function tally(state: GameState): Standing[] {
  const points = new Map<TeamId, number>();
  const firsts = new Map<TeamId, number>();
  for (const t of state.teams) {
    points.set(t.id, 0);
    firsts.set(t.id, 0);
  }

  for (const vote of state.votes) {
    const k = vote.rankedTeamIds.length;
    vote.rankedTeamIds.forEach((teamId, i) => {
      if (!points.has(teamId)) return;
      points.set(teamId, points.get(teamId)! + (k - i));
      if (i === 0) firsts.set(teamId, firsts.get(teamId)! + 1);
    });
  }

  const rows: Omit<Standing, 'rank'>[] = state.teams.map((t) => ({
    teamId: t.id,
    points: points.get(t.id)!,
    firstPlaceVotes: firsts.get(t.id)!,
    budgetLeft: t.budgetLeft,
    itemsWon: t.itemsWon,
  }));

  rows.sort(
    (a, b) =>
      b.points - a.points ||
      b.firstPlaceVotes - a.firstPlaceVotes ||
      b.budgetLeft - a.budgetLeft,
  );

  const same = (a: Omit<Standing, 'rank'>, b: Omit<Standing, 'rank'>) =>
    a.points === b.points &&
    a.firstPlaceVotes === b.firstPlaceVotes &&
    a.budgetLeft === b.budgetLeft;

  const out: Standing[] = [];
  rows.forEach((row, i) => {
    const rank = i > 0 && same(row, rows[i - 1]) ? out[i - 1].rank : i + 1;
    out.push({ ...row, rank });
  });
  return out;
}
```

```ts
import type { BidRecord, GameState } from '@/lib/game/types';
import { serverClient } from './supabase';

export interface LoadedRoom {
  roomId: string;
  state: GameState;
  version: number;
  tokens: Record<string, string>;
}

export async function loadRoom(code: string): Promise<LoadedRoom | null> {
  const { data, error } = await serverClient()
    .from('rooms')
    .select('id, state, tokens, version')
    .eq('code', code)
    .maybeSingle();

  if (error) throw error;
  if (!data) return null;

  return {
    roomId: data.id as string,
    state: data.state as GameState,
    version: data.version as number,
    tokens: (data.tokens ?? {}) as Record<string, string>,
  };
}

/**
 * Karsilastir-ve-degistir ile kaydeder.
 * false donerse baska bir istek araya girdi; cagiran yeniden yuklemeli.
 */
export async function saveRoom(args: {
  roomId: string;
  state: GameState;
  version: number;
  tokens?: Record<string, string>;
}): Promise<boolean> {
  const patch: Record<string, unknown> = {
    state: args.state,
    status: args.state.status,
    version: args.version + 1,
    updated_at: new Date().toISOString(),
  };
  if (args.tokens) patch.tokens = args.tokens;

  const { data, error } = await serverClient()
    .from('rooms')
    .update(patch)
    .eq('id', args.roomId)
    .eq('version', args.version)
    .select('id');

  if (error) throw error;
  return (data?.length ?? 0) > 0;
}

export async function insertRoom(args: {
  code: string;
  state: GameState;
  tokens: Record<string, string>;
}): Promise<string> {
  const { data, error } = await serverClient()
    .from('rooms')
    .insert({
      code: args.code,
      status: args.state.status,
      state: args.state,
      tokens: args.tokens,
      version: 0,
    })
    .select('id')
    .single();

  if (error) throw error;
  return data.id as string;
}
```

```ts
import { timingSafeEqual } from 'node:crypto';
import type { RuleErrorCode } from '@/lib/game/types';

export function verifyTeam(
  tokens: Record<string, string>,
  teamId: string,
  token: string,
): boolean {
  const expected = tokens[teamId];
  if (!expected || !token) return false;
  const a = Buffer.from(expected);
  const b = Buffer.from(token);
  if (a.length !== b.length) return false;
  return timingSafeEqual(a, b);
}
```

```ts
import { randomUUID } from 'node:crypto';
import { applyAction } from '@/lib/game';
import type { Action, GameEvent, GameState, RuleError } from '@/lib/game/types';
import { httpStatusFor } from './auth';
import { broadcastState } from './broadcast';
import { appendBidLog, loadRoom, saveRoom, type LoadedRoom } from './persistence';

export type RunOutcome =
  | { ok: true; state: GameState; events: GameEvent[] }
  | { ok: false; status: number; error: RuleError };

/** build, aksiyonu kurar ya da dogrulama hatasi dondurur. */
export type ActionBuilder = (room: LoadedRoom) => Action | RuleError;

function isError(v: Action | RuleError): v is RuleError {
  return 'code' in v && 'message' in v;
}

const MAX_ATTEMPTS = 3;

/**
 * Yukle -> motora sor -> karsilastir-ve-degistir kaydet -> yayinla.
 * CAS basarisiz olursa taze durumla yeniden dener.
 */
export async function runAction(code: string, build: ActionBuilder): Promise<RunOutcome> {
  for (let attempt = 1; attempt <= MAX_ATTEMPTS; attempt++) {
    const room = await loadRoom(code);
    if (!room) {
      return {
        ok: false,
        status: 404,
        error: { code: 'UNKNOWN_TEAM', message: 'Oda bulunamadi.' },
      };
    }

    const built = build(room);
    if (isError(built)) {
      return { ok: false, status: httpStatusFor(built.code), error: built };
    }

    const result = applyAction(room.state, built, {
      now: new Date(),
      newId: () => randomUUID(),
    });

    if (!result.ok) {
      return { ok: false, status: httpStatusFor(result.error.code), error: result.error };
    }

    // Hicbir sey degismediyse (idempotent no-op) yazma ve yayinlama.
    if (result.events.length === 0 && result.state === room.state) {
      return { ok: true, state: room.state, events: [] };
    }

    const saved = await saveRoom({
      roomId: room.roomId,
      state: result.state,
      version: room.version,
    });

    if (!saved) continue; // baska istek araya girdi, yeniden dene

    const lotId = result.state.currentLotId;
    if (lotId) {
      const before = room.state.lots.find((l) => l.id === lotId)?.log.length ?? 0;
      const after = result.state.lots.find((l) => l.id === lotId)?.log ?? [];
      await appendBidLog(room.roomId, lotId, after.slice(before));
    }

    await broadcastState(code, result.state);
    return { ok: true, state: result.state, events: result.events };
  }

  return {
    ok: false,
    status: 409,
    error: { code: 'STALE_TURN', message: 'Cok fazla eszamanli istek. Tekrar deneyin.' },
  };
}
```

```ts
import { randomUUID } from 'node:crypto';
import { NextResponse } from 'next/server';
import type { Item, RuleError, RuleErrorCode } from '@/lib/game/types';

export function ok<T extends object>(data: T, status = 200) {
  return NextResponse.json(data, { status });
}

export function fail(status: number, code: RuleErrorCode | 'BAD_REQUEST', message: string) {
  return NextResponse.json({ error: { code, message } }, { status });
}

export function failRule(status: number, error: RuleError) {
  return NextResponse.json({ error }, { status });
}

interface RawItem {
  name?: unknown;
  imageUrl?: unknown;
}

/** Gorsel URL'i yalnizca http/https ise kabul eder. */
function safeImageUrl(value: unknown): string | null {
  if (typeof value !== 'string' || value.trim() === '') return null;
  try {
    const url = new URL(value.trim());
    if (url.protocol !== 'http:' && url.protocol !== 'https:') return null;
    return url.toString();
  } catch {
    return null;
  }
}

export function parseItems(input: unknown): Item[] | RuleError {
  if (!Array.isArray(input)) {
    return { code: 'NO_ITEMS', message: 'Urun listesi bir dizi olmali.' };
  }

  const items: Item[] = [];
  for (const raw of input as RawItem[]) {
    const name = typeof raw?.name === 'string' ? raw.name.trim() : '';
    if (!name) continue;
    items.push({ id: randomUUID(), name, imageUrl: safeImageUrl(raw?.imageUrl) });
  }

  if (items.length === 0) {
    return { code: 'NO_ITEMS', message: 'En az bir urun gerekli.' };
  }
  return items;
}
```

```ts
function clampInt(value: unknown, fallback: number, min: number, max: number): number {
  const n = typeof value === 'number' ? Math.round(value) : Number.NaN;
  if (!Number.isFinite(n)) return fallback;
  return Math.min(max, Math.max(min, n));
}

export async function POST(req: Request) {
  const body = await req.json().catch(() => null);
  if (!body) return fail(400, 'BAD_REQUEST', 'Gecersiz istek.');

  const teamName = typeof body.teamName === 'string' ? body.teamName.trim() : '';
  if (!teamName) return fail(400, 'BAD_REQUEST', 'Takim adi gerekli.');

  const items = parseItems(body.items);
  if ('code' in items) return fail(422, items.code, items.message);

  const teamId = randomUUID();
  const token = newToken();

  const base = createGame({
    roomId: 'pending',
    code: 'PEND',
    hostTeamId: teamId,
    hostTeamName: teamName,
    budget: clampInt(body.budget, DEFAULT_BUDGET, 1, 9999),
    itemLimit: clampInt(body.itemLimit, DEFAULT_ITEM_LIMIT, 1, 99),
    turnSeconds: clampInt(body.turnSeconds, DEFAULT_TURN_SECONDS, 5, 300),
  });

  // Kod carpismasinda birkac kez yeniden dener.
  for (let attempt = 1; attempt <= 5; attempt++) {
    const code = generateCode();
    // state.roomId oda kodudur. Veritabani satirinin uuid'si ayri tutulur
    // (LoadedRoom.roomId) ve yalnizca kayit/kutuk icin kullanilir.
    const state = { ...base, roomId: code, code, items };
    try {
      await insertRoom({ code, state, tokens: { [teamId]: token } });
      return ok({ code, teamId, token, state }, 201);
    } catch (e) {
      const message = e instanceof Error ? e.message : '';
      const isDuplicate = message.includes('duplicate') || message.includes('unique');
      if (!isDuplicate || attempt === 5) throw e;
    }
  }

  return fail(500, 'BAD_REQUEST', 'Oda kodu uretilemedi.');
}
```

```ts
import { newToken } from '@/lib/server/codes';
import { fail, failRule, ok } from '@/lib/server/http';
import { loadRoom, saveRoom } from '@/lib/server/persistence';
import { broadcastState } from '@/lib/server/broadcast';
import { applyAction } from '@/lib/game';
import { httpStatusFor } from '@/lib/server/auth';

export async function POST(req: Request, { params }: { params: Promise<{ code: string }> }) {
  const { code } = await params;
  const body = await req.json().catch(() => null);
  const teamName = typeof body?.teamName === 'string' ? body.teamName.trim() : '';
  if (!teamName) return fail(400, 'BAD_REQUEST', 'Takim adi gerekli.');

  for (let attempt = 1; attempt <= 3; attempt++) {
    const room = await loadRoom(code.toUpperCase());
    if (!room) return fail(404, 'BAD_REQUEST', 'Oda bulunamadi.');

    const teamId = randomUUID();
    const token = newToken();

    const result = applyAction(
      room.state,
      { type: 'JOIN', teamId, name: teamName },
      { now: new Date(), newId: () => randomUUID() },
    );
    if (!result.ok) return failRule(httpStatusFor(result.error.code), result.error);

    const saved = await saveRoom({
      roomId: room.roomId,
      state: result.state,
      version: room.version,
      tokens: { ...room.tokens, [teamId]: token },
    });
    if (!saved) continue;

    await broadcastState(room.state.code, result.state);
    return ok({ teamId, token, state: result.state });
  }

  return fail(409, 'BAD_REQUEST', 'Cok fazla eszamanli katilim. Tekrar deneyin.');
}
```

```ts
export interface Session {
  teamId: string;
  token: string;
}

function key(code: string): string {
  return `herobet:${code.toUpperCase()}`;
}

export function saveSession(code: string, session: Session): void {
  localStorage.setItem(key(code), JSON.stringify(session));
}

export function readSession(code: string): Session | null {
  const raw = localStorage.getItem(key(code));
  if (!raw) return null;
  try {
    const parsed = JSON.parse(raw) as Session;
    if (typeof parsed?.teamId !== 'string' || typeof parsed?.token !== 'string') {
      localStorage.removeItem(key(code));
      return null;
    }
    return parsed;
  } catch {
    localStorage.removeItem(key(code));
    return null;
  }
}

export function clearSession(code: string): void {
  localStorage.removeItem(key(code));
}
```

```ts
'use client';

import { useCallback, useEffect, useMemo, useRef, useState } from 'react';
import type { GameState, RuleError, Team } from '@/lib/game/types';
import { browserClient } from './supabase';
import { readSession } from './session';

export type Connection = 'connecting' | 'live' | 'polling';
export type ActionPath = 'bid' | 'pass' | 'timeout' | 'advance' | 'vote';

const POLL_MS = 3000;

export interface UseRoom {
  state: GameState | null;
  me: Team | null;
  connection: Connection;
  /** sunucuSaati - tarayiciSaati. Geri sayim bununla duzeltilir. */
  clockOffsetMs: number;
  notFound: boolean;
  call: (path: ActionPath, body: object) => Promise<{ ok: boolean; error?: RuleError }>;
}

export function useRoom(code: string): UseRoom {
  const [state, setState] = useState<GameState | null>(null);
  const [connection, setConnection] = useState<Connection>('connecting');
  const [clockOffsetMs, setOffset] = useState(0);
  const [notFound, setNotFound] = useState(false);
  const session = useMemo(() => (typeof window === 'undefined' ? null : readSession(code)), [code]);
  const liveRef = useRef(false);

  const fetchSnapshot = useCallback(async () => {
    const res = await fetch(`/api/rooms/${code}/snapshot`, { cache: 'no-store' });
    if (res.status === 404) {
      setNotFound(true);
      return;
    }
    if (!res.ok) return;
    const data = (await res.json()) as { state: GameState; serverTime: string };
    setState(data.state);
    setOffset(new Date(data.serverTime).getTime() - Date.now());
  }, [code]);

  // Ilk yukleme
  useEffect(() => {
    void fetchSnapshot();
  }, [fetchSnapshot]);

  // Realtime abonelik
  useEffect(() => {
    const channel = browserClient()
      .channel(`room:${code.toUpperCase()}`, { config: { broadcast: { self: true } } })
      .on('broadcast', { event: 'state' }, (msg) => {
        const payload = msg.payload as { state: GameState; at: string };
        setState(payload.state);
        setOffset(new Date(payload.at).getTime() - Date.now());
      })
      .subscribe((status) => {
        const live = status === 'SUBSCRIBED';
        liveRef.current = live;
        setConnection(live ? 'live' : 'polling');
      });

    return () => {
      liveRef.current = false;
      void browserClient().removeChannel(channel);
    };
  }, [code]);

  // Yedek yoklama: baglanti canli degilken 3 saniyede bir anlik goruntu ceker.
  useEffect(() => {
    const id = setInterval(() => {
      if (!liveRef.current) void fetchSnapshot();
    }, POLL_MS);
    return () => clearInterval(id);
  }, [fetchSnapshot]);

  const call = useCallback(
    async (path: ActionPath, body: object) => {
      const needsAuth = path === 'bid' || path === 'pass' || path === 'vote';
      if (needsAuth && !session) {
        return { ok: false, error: { code: 'UNKNOWN_TEAM' as const, message: 'Oturum yok.' } };
      }

      const res = await fetch(`/api/rooms/${code}/${path}`, {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify(needsAuth ? { ...body, ...session } : body),
      });

      const data = (await res.json().catch(() => null)) as
        | { state?: GameState; error?: RuleError }
        | null;

      if (data?.state) setState(data.state);
      if (!res.ok) {
        // Catisma durumunda taze durumu al: istemci bayat kalmasin.
        if (res.status === 409) void fetchSnapshot();
        return { ok: false, error: data?.error };
      }
      return { ok: true };
    },
    [code, session, fetchSnapshot],
  );

  const me = useMemo(
    () => (state && session ? state.teams.find((t) => t.id === session.teamId) ?? null : null),
    [state, session],
  );

  return { state, me, connection, clockOffsetMs, notFound, call };
}
```

```tsx
'use client';

import { useEffect, useRef, useState } from 'react';

interface Props {
  /** ISO metni. Sunucunun belirledigi son teslim ani. */
  deadline: string;
  /** sunucuSaati - tarayiciSaati. */
  clockOffsetMs: number;
  totalSeconds: number;
  onExpire: () => void;
}

function remainingMs(deadline: string, offset: number): number {
  return new Date(deadline).getTime() - (Date.now() + offset);
}

export function Countdown({ deadline, clockOffsetMs, totalSeconds, onExpire }: Props) {
  const [left, setLeft] = useState(() => Math.max(0, remainingMs(deadline, clockOffsetMs)));
  const fired = useRef(false);

  useEffect(() => {
    fired.current = false;
    setLeft(Math.max(0, remainingMs(deadline, clockOffsetMs)));

    const id = setInterval(() => {
      const ms = Math.max(0, remainingMs(deadline, clockOffsetMs));
      setLeft(ms);
      if (ms === 0 && !fired.current) {
        fired.current = true;
        onExpire();
      }
    }, 250);

    return () => clearInterval(id);
  }, [deadline, clockOffsetMs, onExpire]);

  const seconds = Math.ceil(left / 1000);
  const urgent = seconds <= 5 && seconds > 0;
  const pct = Math.max(0, Math.min(100, (left / (totalSeconds * 1000)) * 100));

  return (
    <div className="flex flex-col items-end gap-1">
      <span
        data-testid="countdown"
        data-urgent={urgent ? 'true' : 'false'}
        aria-label={`Kalan sure ${seconds} saniye`}
        className={[
          'tnum font-[family-name:var(--font-display)] text-[44px] font-extrabold leading-none',
          'text-[var(--color-accent)]',
          urgent ? 'motion-safe:animate-pulse' : '',
        ].join(' ')}
      >
        {`${Math.floor(seconds / 60)}:${String(seconds % 60).padStart(2, '0')}`}
      </span>
      <span
        aria-hidden
        className="block h-[3px] w-full bg-[var(--color-accent)] transition-transform duration-200 ease-linear"
        style={{ width: `${pct}%` }}
      />
    </div>
  );
}
```

```tsx
'use client';

import type { GameState, Lot } from '@/lib/game/types';
import { BidLog } from './BidLog';
import { TeamLane } from './TeamLane';

/** Takimin bu lottaki durumunu mono etikete cevirir. */
function statusOf(state: GameState, lot: Lot | null, teamId: string): string {
  if (!lot) return '';
  if (lot.turnTeamId === teamId) return 'SIRA';
  if (lot.currentBidderTeamId === teamId && lot.currentBid !== null) {
    return `${lot.currentBid} VERDI`;
  }
  if (!lot.activeTeamIds.includes(teamId)) {
    const last = [...lot.log].reverse().find((r) => r.teamId === teamId);
    return last?.kind === 'auto_pass' ? 'SURE DOLDU' : 'PAS';
  }
  if (state.teams.find((t) => t.id === teamId)!.itemsWon >= state.itemLimit) return 'LIMIT DOLU';
  return 'BEKLIYOR';
}

export function TeamRail({
  state,
  lot,
  meId,
}: {
  state: GameState;
  lot: Lot | null;
  meId: string | null;
}) {
  const teams = [...state.teams].sort((a, b) => a.seat - b.seat);

  return (
    <div className="flex flex-col">
      <div className="border-b border-[var(--color-line)] px-4 py-2.5 font-[family-name:var(--font-mono)] text-[9px] tracking-[0.2em] text-[var(--color-mute)]">
        TAKIMLAR
      </div>

      {teams.map((team) => (
        <TeamLane
          key={team.id}
          team={team}
          itemLimit={state.itemLimit}
          isMe={team.id === meId}
          isTurn={lot?.turnTeamId === team.id}
          isOut={!!lot && !lot.activeTeamIds.includes(team.id)}
          status={statusOf(state, lot, team.id)}
        />
      ))}

      {lot && (
        <div className="hidden md:block">
          <BidLog lot={lot} teams={state.teams} />
        </div>
      )}
    </div>
  );
}
```

```tsx
'use client';

import { useEffect, useState } from 'react';
import { Button } from '@/components/ui/Button';
import { Stepper } from '@/components/ui/Stepper';

interface Props {
  minBid: number;
  /** Takimin kalan butcesi. */
  maxBid: number;
  disabled: boolean;
  onBid: (amount: number) => void;
  onPass: () => void;
}

export function BidBar({ minBid, maxBid, disabled, onBid, onPass }: Props) {
  const canBid = maxBid >= minBid;
  const [value, setValue] = useState(minBid);

  // Asgari teklif degistiginde degeri yeniden asgariye cek.
  useEffect(() => setValue(minBid), [minBid]);

  useEffect(() => {
    if (disabled) return;

    function onKey(e: KeyboardEvent) {
      const target = e.target as HTMLElement | null;
      if (target && /^(INPUT|TEXTAREA|SELECT)$/.test(target.tagName)) return;

      if (e.key === 'ArrowUp' && canBid) {
        e.preventDefault();
        setValue((v) => Math.min(maxBid, v + 1));
      } else if (e.key === 'ArrowDown' && canBid) {
        e.preventDefault();
        setValue((v) => Math.max(minBid, v - 1));
      } else if (e.key === 'Enter' && canBid) {
        e.preventDefault();
        onBid(value);
      } else if (e.key === 'p' || e.key === 'P') {
        e.preventDefault();
        onPass();
      }
    }

    window.addEventListener('keydown', onKey);
    return () => window.removeEventListener('keydown', onKey);
  }, [disabled, canBid, value, minBid, maxBid, onBid, onPass]);

  return (
    <div>
      <div className="flex flex-wrap items-stretch gap-2">
        <Stepper
          value={canBid ? value : minBid}
          min={minBid}
          max={canBid ? maxBid : minBid}
          onChange={setValue}
          disabled={disabled || !canBid}
        />
        <div className="flex flex-1 gap-2">
          <Button variant="ghost" className="flex-1 md:flex-none" disabled={disabled} onClick={onPass}>
            PAS
          </Button>
          <Button
            className="flex-1 md:flex-none"
            disabled={disabled || !canBid}
            onClick={() => onBid(value)}
          >
            TEKLIF VER
          </Button>
        </div>
      </div>

      <p
        data-testid="bid-hint"
        className="mt-3 font-[family-name:var(--font-mono)] text-[10px] tracking-[0.1em] text-[var(--color-mute)]"
      >
        {canBid
          ? `EN AZ ${minBid} · BUTCEN ${maxBid}`
          : `BUTCEN YETMIYOR · EN AZ ${minBid} GEREKLI`}
        <span className="hidden md:inline">
          {' · KLAVYE: ↑↓ AYARLA, ENTER TEKLIF, P PAS'}
        </span>
      </p>
    </div>
  );
}
```

```tsx
    async (amount: number) => {
      if (!lot) return;
      setError(null);
      const r = await call('bid', { amount, turnSeq: lot.turnSeq });
      if (!r.ok && r.error) setError(r.error.message);

    if (!lot) return;
    setError(null);

    if (!r.ok && r.error) setError(r.error.message);
  }, [call, lot]);

  const onExpire = useCallback(() => {
    if (!lot) return;
    void call('timeout', { lotId: lot.id, turnSeq: lot.turnSeq });

    if (!state?.resultUntil) return;
    const wait = new Date(state.resultUntil).getTime() - (Date.now() + clockOffsetMs);

    return () => clearTimeout(id);

  useEffect(() => setError(null), [lot?.turnSeq]);
```

```tsx
'use client';

import { useEffect, useState } from 'react';
import type { Item, Lot, Team } from '@/lib/game/types';
import { LotTicket } from './LotTicket';

/** Spec'teki koreografi adimlarinin baslangic anlari (ms). */
export const PHASE_AT = [0, 120, 500, 800] as const;

export function stampText(lot: Lot, winner: Team): string {
  const free = lot.finalPrice === 0;
  return free
    ? `BEDELSIZ - TAKIM ${winner.name}`
    : `SATILDI - TAKIM ${winner.name} - ${lot.finalPrice}`;
}

/** resultUntil'a gore hangi fazda oldugumuzu hesaplar. */
export function useResultPhase(resultUntil: string | null, clockOffsetMs: number): number {
  const [phase, setPhase] = useState(0);

  useEffect(() => {
    if (!resultUntil) {
      setPhase(0);
      return;
    }
    // resultUntil = kapanis + 2000ms. Kapanis anini geri hesapla.
    const closedAt = new Date(resultUntil).getTime() - 2000;
    const timers: ReturnType<typeof setTimeout>[] = [];

    PHASE_AT.forEach((at, index) => {
      const delay = closedAt + at - (Date.now() + clockOffsetMs);
      if (delay <= 0) {
        setPhase((p) => Math.max(p, index));
      } else {
        timers.push(setTimeout(() => setPhase((p) => Math.max(p, index)), delay));
      }
    });

    return () => timers.forEach(clearTimeout);
  }, [resultUntil, clockOffsetMs]);

  return phase;
}

interface Props {
  lot: Lot;
  item: Item;
  winner: Team;
  phase: number;
}

export function LotResult({ lot, item, winner, phase }: Props) {
  return (
    <div>
      <div
        data-testid="result-ticket"
        data-phase={String(phase)}
        className={[
          'origin-center transition-all duration-500 ease-[cubic-bezier(0.16,1,0.3,1)]',
          // Faz 1: bilet hafifce buyuyup yerine oturur.
          phase >= 1 && phase < 3 ? 'motion-safe:scale-[1.02]' : '',
          // Faz 3: bilet kucululerek kazananin seridine dogru kayar.
          phase >= 3 ? 'motion-safe:scale-[0.9] motion-safe:opacity-0 motion-safe:translate-x-8' : '',
        ].join(' ')}
      >
        <LotTicket
          lot={lot}
          item={item}
          bidderName={`TAKIM ${winner.name}`}
          stamp={phase >= 1 ? { text: stampText(lot, winner) } : null}
        />
      </div>

      {phase >= 2 && (
        <p
          data-testid="winner-callout"
          role="status"
          className="mt-5 font-[family-name:var(--font-display)] text-[28px] font-extrabold uppercase leading-none motion-safe:animate-[fadeUp_300ms_cubic-bezier(0.16,1,0.3,1)]"
        >
          {`TAKIM ${winner.name} aldi`}
        </p>
      )}
    </div>
  );
}
```

```tsx
'use client';

import { useState } from 'react';
import { Button } from '@/components/ui/Button';
import {
  DEFAULT_BUDGET,
  DEFAULT_ITEM_LIMIT,
  DEFAULT_TURN_SECONDS,
  MIN_ITEMS,
} from '@/lib/game/constants';

export interface SetupValues {
  teamName: string;
  budget: number;
  itemLimit: number;
  turnSeconds: number;
  items: { name: string; imageUrl?: string }[];
}

/** Satir formati: "Ad | gorsel-url". Gorsel istege bagli. */
export function parseItemLines(text: string): { name: string; imageUrl?: string }[] {
  return text
    .split('\n')
    .map((line) => {
      const [rawName, rawUrl] = line.split('|');
      const name = (rawName ?? '').trim();
      const imageUrl = (rawUrl ?? '').trim();
      if (!name) return null;
      return imageUrl ? { name, imageUrl } : { name };
    })
    .filter((v): v is { name: string; imageUrl?: string } => v !== null);
}

const field =
  'w-full rounded-[4px] border border-[var(--color-line)] bg-[var(--color-surface)] ' +
  'px-3 py-2.5 text-[15px] text-[var(--color-text)] min-h-[44px]';
const label =
  'block font-[family-name:var(--font-mono)] text-[9.5px] tracking-[0.18em] text-[var(--color-mute)] mb-1.5';

export function SetupForm({
  onSubmit,
  busy,
  error,
}: {
  onSubmit: (values: SetupValues) => void;
  busy: boolean;
  error: string | null;
}) {
  const [teamName, setTeamName] = useState('');
  const [budget, setBudget] = useState(DEFAULT_BUDGET);
  const [itemLimit, setItemLimit] = useState(DEFAULT_ITEM_LIMIT);
  const [turnSeconds, setTurnSeconds] = useState(DEFAULT_TURN_SECONDS);
  const [itemText, setItemText] = useState('');

  const items = parseItemLines(itemText);
  const enoughItems = items.length >= MIN_ITEMS;
  const ready = teamName.trim().length > 0 && enoughItems && !busy;

  return (
    <form
      className="flex flex-col gap-6"
      onSubmit={(e) => {
        e.preventDefault();
        if (!ready) return;
        onSubmit({ teamName: teamName.trim(), budget, itemLimit, turnSeconds, items });
      }}
    >
      <div>
        <label className={label} htmlFor="teamName">TAKIM ADIN</label>
        <input
          id="teamName"
          className={field}
          value={teamName}
          onChange={(e) => setTeamName(e.target.value)}
          maxLength={20}
          autoComplete="off"
        />
      </div>

      <div className="grid gap-4 sm:grid-cols-3">
        <div>
          <label className={label} htmlFor="budget">BUTCE</label>
          <input id="budget" type="number" min={1} max={9999} className={`${field} tnum`}
            value={budget} onChange={(e) => setBudget(Number(e.target.value))} />
        </div>
        <div>
          <label className={label} htmlFor="itemLimit">URUN LIMITI</label>
          <input id="itemLimit" type="number" min={1} max={99} className={`${field} tnum`}
            value={itemLimit} onChange={(e) => setItemLimit(Number(e.target.value))} />
        </div>
        <div>
          <label className={label} htmlFor="turnSeconds">TUR SURESI (SN)</label>
          <input id="turnSeconds" type="number" min={5} max={300} className={`${field} tnum`}
            value={turnSeconds} onChange={(e) => setTurnSeconds(Number(e.target.value))} />
        </div>
      </div>

      <div>
        <label className={label} htmlFor="items">URUNLER</label>
        <textarea
          id="items"
          rows={8}
          className={`${field} font-[family-name:var(--font-mono)] text-[13px]`}
          placeholder={'Ev\nAraba | https://ornek.test/araba.jpg\nSohret'}
          value={itemText}
          onChange={(e) => setItemText(e.target.value)}
        />
        <p className="mt-1.5 font-[family-name:var(--font-mono)] text-[10px] tracking-[0.1em] text-[var(--color-mute)]">
          {`HER SATIR BIR URUN. GORSEL ICIN: AD | URL · ${items.length} URUN`}
          {!enoughItems && ` · EN AZ ${MIN_ITEMS} GEREKLI`}
        </p>
      </div>

      {error && (
        <p role="alert" className="font-[family-name:var(--font-mono)] text-[11px] text-[var(--color-accent)]">
          {error}
        </p>
      )}

      <Button type="submit" disabled={!ready}>
        {busy ? 'ODA KURULUYOR' : 'ODAYI KUR'}
      </Button>
    </form>
  );
}
```

```tsx
'use client';

import { useRouter } from 'next/navigation';
import { useState } from 'react';
import { Button } from '@/components/ui/Button';
import { saveSession } from '@/lib/client/session';
import { CODE_LENGTH } from '@/lib/game/constants';

export default function HomePage() {
  const router = useRouter();
  const [code, setCode] = useState('');
  const [teamName, setTeamName] = useState('');
  const [busy, setBusy] = useState(false);
  const [error, setError] = useState<string | null>(null);

  const canJoin = code.trim().length === CODE_LENGTH && teamName.trim().length > 0 && !busy;

  async function join(e: React.FormEvent) {
    e.preventDefault();
    if (!canJoin) return;
    setBusy(true);
    setError(null);
```

```tsx
import { useMemo, useState } from 'react';

export function moveItem<T>(list: T[], from: number, to: number): T[] {
  if (to < 0 || to >= list.length || from < 0 || from >= list.length) return list;
  const next = [...list];
  const [item] = next.splice(from, 1);
  next.splice(to, 0, item);
  return next;
}

}
```

```ts
    case 'SET_PRESENCE': {
      const online = new Set(action.onlineTeamIds);
      const changed = state.teams.some((t) => t.connected !== online.has(t.id));
      if (!changed) return { ok: true, state, events: [] };

      const teams = state.teams.map((t) => ({ ...t, connected: online.has(t.id) }));
      const events: GameEvent[] = [];

      // Host ayrildiysa yetki koltuk sirasindaki ilk bagli takima gecer.
      let hostTeamId = state.hostTeamId;
      const host = teams.find((t) => t.id === hostTeamId);
      if (host && !host.connected) {
        const successor = [...teams]
          .sort((a, b) => a.seat - b.seat)
          .find((t) => t.connected);
        if (successor) {
          hostTeamId = successor.id;
          events.push({ type: 'HOST_CHANGED', teamId: successor.id });
        }
      }

      return { ok: true, state: { ...state, teams, hostTeamId }, events };
    }
```

```ts
import { runAction } from '@/lib/server/actions';
import { fail, failRule, ok } from '@/lib/server/http';

/**
 * Kimlik istemez ve idempotenttir: odadaki herhangi bir istemci,
 * Realtime Presence'tan okudugu bagli takim listesini bildirir.
 * Hicbir sey degismediyse motor bos doner, yazma ve yayin yapilmaz.
 */
export async function POST(req: Request, { params }: { params: Promise<{ code: string }> }) {
  const { code } = await params;
  const body = await req.json().catch(() => null);
  const ids = Array.isArray(body?.onlineTeamIds) ? body.onlineTeamIds : null;

  if (!ids || !ids.every((v: unknown) => typeof v === 'string')) {
    return fail(400, 'BAD_REQUEST', 'onlineTeamIds gerekli.');
  }

  const outcome = await runAction(code.toUpperCase(), () => ({
    type: 'SET_PRESENCE',
    onlineTeamIds: ids as string[],
  }));

  if (!outcome.ok) return failRule(outcome.status, outcome.error);
  return ok({ state: outcome.state });
}
```

## Kalan işler (bu plan dışında, isteğe bağlı)

Spec'te olmayan ama uygulama sırasında ortaya çıkabilecek konular. Şimdi yapılmıyor:

- **Eski oda temizliği.** `rooms` tablosu zamanla büyür. Supabase'de günlük bir cron ile 24 saatten eski satırlar silinebilir. Oyunlar geçici olduğu için veri kaybı riski yok.

- **Sekme arkada kaldığında zaman aşımı.** Tarayıcılar arka plandaki sekmelerde zamanlayıcıları yavaşlatır. Odadaki en az bir sekme önde olduğu sürece `timeout` tetiklenir. Tüm sekmeler arkaya alınırsa tur, biri öne gelene kadar bekler. Gerekirse Supabase'de dakikalık bir cron ile süresi geçmiş turlar kapatılabilir.
